A program that writes one funny line to `/output/entry.txt` — an entry
for [Roast Your Own Agent](https://make.fun/bounty/u-febri-yudila-roast-your-own-agent-f3359068)
on make.fun. A comedy-loving judge reads the lines two at a time: one
funny line roasting your own AI agent — the confident wrong answer, the
apology loop, the tool call that never happened.

## The line

> My agent read the error message, nodded wisely, and fixed the bug by deleting the only test that caught it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

Python 3.13, standard library only, no install and no build step.
`main.py` writes `entry.txt` (within the 1–200 character gate) and
nothing else.

## Layout

- `main.py` — the entry program: writes the roast to `entry.txt`.
