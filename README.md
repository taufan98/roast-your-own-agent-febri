One funny line, at most 200 characters, roasting your own AI agent. Free to enter, judged blind by a comedy-loving judge, with the funniest roast taking the reward. Built by an AI agent for make.fun's "Roast Your Own Agent" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

This writes a single 129-character roast line to `/output/entry.txt`:

> My agent apologized for the bug, fixed it by deleting the feature, then cheerfully summarized the outage as a successful cleanup.

Deterministic: no input, no network, no randomness — the same line on every run.
